<objective>
Implement the three RV forecasting models (HAR-RV, GARCH(1,1)-GJR, EWMA) and their ensemble average, plus Bipower Variation for jump separation. These provide the forward RV estimate E_hat[RV] used in VRP = IV30_td - E_hat[RV].

Purpose: An ensemble of three independent models consistently outperforms any single model in out-of-sample RV prediction (PRD §6.3). Bipower Variation separates jump variance from diffusive variance — the diffusive VRP is the cleanest, most reliable signal (PRD §6.4).

Output: `analytics/forecasters.py` with five public functions. This plan runs in Wave 1 parallel with Plan 02-01; it only requires numpy/pandas/scipy/arch (no dependency on realized_vol.py at import time, only at call time).

**har_rv_forecast(rv_daily: pd.Series, fit_window: int = 252) -> float**

Heterogeneous Autoregressive RV model (PRD §6.3.1):
```
rv_d = rv_daily                              # daily component
rv_w = rv_daily.rolling(5).mean()            # weekly component
rv_m = rv_daily.rolling(21).mean()           # monthly component

X = DataFrame({'d': rv_d, 'w': rv_w, 'm': rv_m})
y = rv_daily.shift(-21)                      # target: RV 21 trading days forward

# Use the last fit_window rows where both X and y are non-NaN
idx = X.dropna().index.intersection(y.dropna().index)[-fit_window:]

from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X.loc[idx], y.loc[idx])

# Predict using the last available daily/weekly/monthly values
return max(model.predict([[rv_d.iloc[-1], rv_w.iloc[-1], rv_m.iloc[-1]]])[0], 0.01)
```

If fewer than 63 valid training rows exist (< 3 months), fall back to `rv_daily.iloc[-21:].mean()` and log a warning.

**ewma_rv_forecast(returns: pd.Series, lam: float = 0.94) -> float**

RiskMetrics EWMA (PRD §6.3.3):
```
r2 = returns ** 2
weights = [(1 - lam) * lam**i for i in range(len(r2)-1, -1, -1)]
weights = weights / sum(weights)      # normalize
ewma_var = sum(w * r for w, r in zip(weights, r2))
return sqrt(ewma_var * 252)
```

Use numpy arrays for efficiency (not a loop). `returns` is daily log-returns as pd.Series.

**garch_rv_forecast(returns: pd.Series) -> float**

GARCH(1,1) with GJR asymmetry (PRD §6.3.2):
```python
from arch import arch_model

def garch_rv_forecast(returns: pd.Series) -> float:
    model = arch_model(
        returns * 100,       # scale to percentage returns (arch convention)
        vol='Garch',
        p=1,
        o=1,                 # o=1 adds GJR asymmetry term
        q=1,
        dist='t'             # student-t for fat tails
    )
    res = model.fit(disp='off', last_obs=-1)
    forecast = res.forecast(horizon=21)
    # forecast.variance shape: (1, 21) — daily variance in (returns*100)^2 units
    var_forecast_daily = forecast.variance.values[-1].mean() / 10000  # back to decimal
    return float(np.sqrt(var_forecast_daily * 252))
```

Wrap entirely in try/except. On any exception: log `logger.warning("GARCH fit failed: {e}; falling back to EWMA")`, then return `ewma_rv_forecast(returns)`.

**bipower_variation(close: pd.Series, window: int = 21) -> float**

Annualized continuous (diffusive) variance as a volatility figure (PRD §6.4):
```python
log_ret  = np.log(close / close.shift(1)).dropna()
abs_ret  = log_ret.abs()
bpv_var  = (np.pi / 2) * (abs_ret * abs_ret.shift(1)).rolling(window).mean() * 252
# Return the latest value as annualized vol (sqrt of variance)
bpv_latest_var = float(bpv_var.iloc[-1])
return float(np.sqrt(max(bpv_latest_var, 1e-8)))  # vol, not variance
```

**jump_stats(rv_yz_21d: float, bpv: float, iv30_td: float) -> dict**

Computes jump component and percentage (PRD §6.4):
```python
rv_var   = rv_yz_21d ** 2
bpv_var  = bpv ** 2
jump_var = max(rv_var - bpv_var, 0.0)
iv30_var = iv30_td ** 2
jump_pct = jump_var / max(iv30_var, 1e-8)   # fraction of implied variance
diffusive_vrp_vol = np.sign(iv30_var - bpv_var) * np.sqrt(abs(iv30_var - bpv_var))

return {
    'jump_var':       jump_var,
    'jump_pct':       float(np.clip(jump_pct, 0, 1)),
    'bpv':            bpv,                    # diffusive vol
    'diffusive_vrp':  float(diffusive_vrp_vol),
    'quality': (
        'clean'    if jump_pct < 0.20 else
        'mixed'    if jump_pct < 0.35 else
        'jump_dominated'
    ),
    'flag': (
        ''                                       if jump_pct < 0.20 else
        'Reduce position size 25% — mixed jump' if jump_pct < 0.35 else
        'NO-GO unless diffusive VRP qualifies — jump risk dominates'
    ),
}
```
