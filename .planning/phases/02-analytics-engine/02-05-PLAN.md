Implement these signals inside compute_vrp_signals. All use `from scipy.stats import percentileofscore`:

**vrp (primary signal):**
```python
vrp = vrp_data['vrp']  # already computed: iv30_td - ensemble_rv
```

**vrp_pctile** — percentile vs 252-day VRP history:
```python
vrp_pctile = percentileofscore(vrp_history.dropna(), vrp, kind='rank') / 100.0
```

**vrp_persist_30d** — fraction of last 30 sessions VRP > 0:
```python
vrp_persist_30d = float((vrp_history.iloc[-30:] > 0).mean()) if len(vrp_history) >= 30 else 0.5
```

**vrp_zscore**:
```python
vrp_zscore = (vrp - float(vrp_history.mean())) / max(float(vrp_history.std()), 1e-8)
```

**vrp_sharpe** — annualized Sharpe of VRP stream (monthly observations, annualized by sqrt(252/21)):
```python
vrp_sharpe = float(vrp_history.mean() / max(vrp_history.std(), 1e-8) * np.sqrt(252/21))
```

**vrp_5d_change, vrp_10d_change** — VRP momentum (PRD §6.9):
```python
vrp_5d_change  = vrp - float(vrp_history.iloc[-5])  if len(vrp_history) >= 5  else 0.0
vrp_10d_change = vrp - float(vrp_history.iloc[-10]) if len(vrp_history) >= 10 else 0.0
vrp_momentum   = int(np.sign(vrp_5d_change))  # +1 rising, -1 falling, 0 flat
```

**excess_vrp** — idiosyncratic premium above beta-adjusted index:
```python
excess_vrp = vrp - (beta * spy_vrp)
```

**ivr** — IV Rank in [0, 1]:
```python
iv52_low  = float(iv30_history.min())
iv52_high = float(iv30_history.max())
ivr = (vrp_data['iv30'] - iv52_low) / max(iv52_high - iv52_low, 1e-8)
ivr = float(np.clip(ivr, 0.0, 1.0))
```

**ivp** — IV Percentile in [0, 1]:
```python
ivp = percentileofscore(iv30_history.dropna(), vrp_data['iv30'], kind='rank') / 100.0
```

# ATM straddle = ATM call mid + ATM put mid
# Find ATM call and put from the nearest-30DTE expiration
atm_call = atm_put = None
for exp in chain['expirations']:
    spot_val = chain['underlying_price']
    atm_call_row = exp['calls'].iloc[(exp['calls']['strike'] - spot_val).abs().argsort()[:1]]
    atm_put_row  = exp['puts'].iloc[(exp['puts']['strike'] - spot_val).abs().argsort()[:1]]
    if len(atm_call_row) and len(atm_put_row):
        atm_call = float((atm_call_row['bid'].values[0] + atm_call_row['ask'].values[0]) / 2)
        atm_put  = float((atm_put_row['bid'].values[0]  + atm_put_row['ask'].values[0])  / 2)
        dte_used  = exp['dte']
        break

if atm_call is not None and atm_put is not None:
    atm_straddle = atm_call + atm_put
    spot_val     = chain['underlying_price']
    rv_21d       = vrp_data.get('ensemble_rv', 0.20)
    em_ratio     = atm_straddle / max(rv_21d * spot_val * np.sqrt(dte_used / 252), 1e-8)
else:
    em_ratio = 1.0   # neutral default
```

def vrp_timing_signal(vrp_5d_change, vrp_10d_change, vrp_pctile):
    is_rising  = vrp_5d_change > 0.005   # >0.5 vol pts (0.005 in annualized decimal)
    is_falling = vrp_5d_change < -0.005

    if is_falling and vrp_pctile > 0.65:
        return "ENTER NOW", "VRP is contracting — premium collapsing toward mean. Enter immediately."
    elif is_rising and vrp_pctile > 0.80:
        return "ENTER NOW or WAIT 1-3 DAYS", "VRP is expanding at 80th+ pctile. Can enter now or wait for peak."
    elif is_rising and vrp_pctile < 0.70:
        return "WAIT 1-3 DAYS", "VRP expanding but below threshold. Let premium build before entering."
    else:
        return "ENTER AT OPPORTUNITY", "VRP stable at elevated level. Enter on minor IV spike or underlying dip."
```

Note: PRD uses "0.5 vol pts" as threshold. Since VRP in this codebase is in annualized decimal (e.g., 0.03 = 3 vol pts), the threshold is 0.005 (0.5 vol pts in decimal). Add this comment in the code.
