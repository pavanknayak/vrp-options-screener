**bsm_price(S, K, T, r, sigma, option_type='call') -> float**

Black-Scholes-Merton option price (internal helper, not exported):
```
d1 = (log(S/K) + (r + sigma^2/2)*T) / (sigma * sqrt(T))
d2 = d1 - sigma * sqrt(T)
if call:   price = S*N(d1) - K*exp(-r*T)*N(d2)
if put:    price = K*exp(-r*T)*N(-d2) - S*N(-d1)
```
Use `scipy.stats.norm.cdf`. Return `max(price, 0.0)`.

If T <= 0 or sigma <= 0: return intrinsic value `max(S-K, 0)` for calls, `max(K-S, 0)` for puts.

**bsm_iv(market_price: float, S: float, K: float, T: float, r: float, option_type: str = 'call') -> float | None**

BSM IV inversion using Brent's method (scipy.optimize.brentq):
```python
from scipy.optimize import brentq

def bsm_iv(market_price, S, K, T, r, option_type='call'):
    intrinsic = max(S-K, 0) if option_type=='call' else max(K-S, 0)
    if market_price <= intrinsic + 1e-6:
        return None   # deep ITM or bad data — skip
    if T <= 0:
        return None

    def objective(sigma):
        return bsm_price(S, K, T, r, sigma, option_type) - market_price

    try:
        iv = brentq(objective, 1e-4, 20.0, xtol=1e-6, maxiter=100)
        return float(iv) if 0.01 <= iv <= 15.0 else None
    except ValueError:
        return None   # no root in [1e-4, 20] — option price outside BSM range
```

Checks for calendar-arbitrage-free condition in total-variance space. Total variance w(K) = IV(K)^2 × T must be non-decreasing in T across expirations (checked at the plan level). Within a single expiration, check for negative butterfly (convexity violation):

**fit_iv_smile(strikes: np.ndarray, ivs: np.ndarray) -> scipy.interpolate.PchipInterpolator | None**

PCHIP monotone-cubic spline fit to the IV smile (PRD §5 Stage 2 Step 4):
```python
from scipy.interpolate import PchipInterpolator

def fit_iv_smile(strikes, ivs):
    valid = np.isfinite(ivs) & (ivs > 0.01)
    s, v = strikes[valid], ivs[valid]
    if len(s) < 3:
        return None
    order = np.argsort(s)
    # PCHIP ensures monotone cubic — no spurious oscillations in the smile
    return PchipInterpolator(s[order], v[order], extrapolate=False)
```

The caller uses this to evaluate ATM IV by passing `spot` as the query point.

**interpolate_iv_surface(chain: dict, spot: float, r: float) -> dict**

Given Schwab chain dict `{"underlying_price": float, "expirations": [...]}`, compute IV30 and IV60 by interpolation in total-variance space (PRD §5 Stage 2 Steps 3-6):

```python
def interpolate_iv_surface(chain, spot, r):
    # Step 1: per-expiration IV extraction
    exp_ivs = []   # list of (dte, atm_iv)
    for exp in chain['expirations']:
        dte = exp['dte']
        T   = dte / 365.0    # calendar-day fraction for BSM

        calls, puts = filter_chain_options(exp['calls'], exp['puts'], spot)

        # Per-strike BSM inversion
        ivs_list = []
        for _, row in puts.iterrows():
            mid = (row['bid'] + row['ask']) / 2.0
            iv  = bsm_iv(mid, spot, row['strike'], T, r, 'put')
            if iv is not None:
                ivs_list.append((row['strike'], iv))
        for _, row in calls.iterrows():
            mid = (row['bid'] + row['ask']) / 2.0
            iv  = bsm_iv(mid, spot, row['strike'], T, r, 'call')
            if iv is not None:
                ivs_list.append((row['strike'], iv))

        if len(ivs_list) < 3:
            continue

        strikes = np.array([x[0] for x in ivs_list])
        ivs     = np.array([x[1] for x in ivs_list])

        smile = fit_iv_smile(strikes, ivs)
        if smile is None:
            continue

        atm_iv = float(smile(spot))
        if not np.isfinite(atm_iv) or atm_iv <= 0:
            # PCHIP extrapolation returned NaN at spot — use nearest valid IV
            dists = np.abs(strikes - spot)
            atm_iv = float(ivs[np.argmin(dists)])

        exp_ivs.append({'dte': dte, 'atm_iv': atm_iv, 'total_var': atm_iv**2 * dte})

    if len(exp_ivs) < 2:
        return {'iv30': None, 'iv60': None, 'error': 'Insufficient expirations for interpolation'}

    # Step 2: sort by DTE and interpolate in total-variance space
    exp_ivs.sort(key=lambda x: x['dte'])
    dtes     = np.array([e['dte'] for e in exp_ivs])
    tot_vars = np.array([e['total_var'] for e in exp_ivs])

    # Check no negative forward variance (tot_var must be non-decreasing in DTE)
    has_arb = bool(np.any(np.diff(tot_vars) < -1e-6))
    if has_arb:
        logger.warning("Negative forward variance detected — IV surface has arbitrage")

    # Linear interpolation in total-variance space
    iv30 = _interp_tv(dtes, tot_vars, target_dte=30)
    iv60 = _interp_tv(dtes, tot_vars, target_dte=60)

    return {
        'iv30':        iv30,
        'iv60':        iv60,
        'exp_ivs':     exp_ivs,
        'has_arbitrage': has_arb,
    }

def _interp_tv(dtes, tot_vars, target_dte):
    """Interpolate (or extrapolate) total variance at target_dte, return annualized vol."""
    tv = float(np.interp(target_dte, dtes, tot_vars))
    if tv <= 0 or not np.isfinite(tv):
        return None
    return float(np.sqrt(tv / target_dte))   # annualized vol from total variance
```

**compute_vrp(chain: dict, ohlc: pd.DataFrame, r: float) -> dict**

Top-level function that combines IV surface + ensemble RV forecast to produce VRP (PRD §2.1, §6.3.4):

```python
from analytics.realized_vol import iv_to_trading_day
from analytics.forecasters import ensemble_rv_forecast

def compute_vrp(chain, ohlc, r):
    spot    = chain['underlying_price']
    returns = np.log(ohlc['Close'] / ohlc['Close'].shift(1)).dropna()

    surface = interpolate_iv_surface(chain, spot, r)
    if surface.get('iv30') is None:
        return {'error': 'IV surface failed', **surface}

    # Convert calendar-day IV to trading-day basis for fair comparison with RV
    iv30_td = iv_to_trading_day(surface['iv30'])
    iv60_td = iv_to_trading_day(surface['iv60']) if surface['iv60'] else None

    ens     = ensemble_rv_forecast(ohlc, returns)
    vrp     = iv30_td - ens['ensemble']

    return {
        'iv30':        surface['iv30'],
        'iv60':        surface.get('iv60'),
        'iv30_td':     iv30_td,
        'iv60_td':     iv60_td,
        'vrp':         vrp,
        'ensemble_rv': ens['ensemble'],
        'har':         ens['har'],
        'garch':       ens['garch'],
        'ewma':        ens['ewma'],
        'has_arbitrage': surface.get('has_arbitrage', False),
        'exp_ivs':     surface.get('exp_ivs', []),
    }
```
