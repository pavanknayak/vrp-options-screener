Create `universe/loader.py`. Import `tickers.json` at module load and build an in-memory lookup dict.

Define `TickerInfo` dataclass:
```python
from dataclasses import dataclass, field
from typing import Optional

@dataclass
class TickerInfo:
    symbol: str
    tier: str                          # e.g. "1A", "1I", "6B"
    tier_description: str
    asset_class: str                   # e.g. "crypto_etf", "china_adr", "us_equity"
    permitted_structures: list[str]    # e.g. ["spread","collar"]
    max_position_pct: float            # 0.05 default, 0.02 for crypto
    requires_fundamental_score: bool   # False for ETFs, True for equity tiers 2-7
    options_filter: dict               # atm_bid_ask_max_pct, min_oi, etc.
    no_entry_days: list[str] = field(default_factory=list)  # ["thursday_after_2pm","friday"] for 1I
    notes: Optional[str] = None        # per-ticker override notes
```

Implement `load_universe() -> dict[str, TickerInfo]`:
- Load `universe/tickers.json` relative to this file's directory
- For each tier, for each ticker (handling both string and dict forms):
  - Resolve effective `permitted_structures`: use `override_structures` if present in per-ticker dict, else tier default
  - Build `TickerInfo` with all fields
- Return flat dict: `{"SPY": TickerInfo(...), "IBIT": TickerInfo(...), ...}`

Implement `get_ticker_info(symbol: str) -> Optional[TickerInfo]`:
- Returns from the module-level pre-loaded `UNIVERSE` dict (case-insensitive lookup using `.upper()`)
- Returns `None` if ticker not found (not in universe)

Module-level: `UNIVERSE: dict[str, TickerInfo] = load_universe()` — loaded once at import.

`universe/__init__.py` exports: `TickerInfo`, `load_universe`, `get_ticker_info`, `UNIVERSE`.

Keep import-time side effects minimal — only the JSON load. No network calls.
