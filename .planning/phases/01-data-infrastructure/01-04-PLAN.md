Create `data/schwab_client.py`. Implement Schwab OAuth2 integration using the `schwab-py` library.

**Client initialization** — `get_schwab_client()`:
- Read `SCHWAB_APP_KEY` and `SCHWAB_APP_SECRET` from environment variables
- If either is missing: log a warning and return `None` (do not raise — app must start without Schwab credentials; Schwab features will be disabled)
- Use `schwab.auth.easy_client()` with:
  - `api_key=SCHWAB_APP_KEY`
  - `app_secret=SCHWAB_APP_SECRET`
  - `callback_url='https://127.0.0.1'`
  - `token_path=str(Path(__file__).parent.parent / 'schwab_token.json')`
- `easy_client()` handles the full OAuth flow: if token file exists and is valid → uses it silently; if expired → auto-refreshes; if no file → opens browser for authorization code flow
- Cache the client object in a module-level variable `_client = None` and return it on subsequent calls (do not reinitialize per call)
- Wrap in try/except; on any exception return `None` and log the error

**`schwab_connection_status() -> dict`**:
- Returns `{"connected": bool, "message": str, "token_path": str}`
- `connected=True` if `get_schwab_client()` returns non-None
- `message`: e.g. "Connected — token valid" or "Not connected — SCHWAB_APP_KEY not set" or "Not connected — token expired"

**`fetch_options_chain(ticker: str, min_dte: int = 25, max_dte: int = 55) -> Optional[dict]`**:
- Cache key: `f"{ticker.upper()}_schwab_options_{datetime.now().strftime('%Y%m%d_%H%M'[:13])}"`  (hour-level granularity to group within TTL)
- TTL: `TTL["options_chain_live"]` (900 seconds)
- If cache hit: return cached dict
- client = `get_schwab_client()`; if None: return `None` (Schwab not configured)
- Find 2-3 expiration dates bracketing min_dte to max_dte:
  - Call `client.get_option_chain(ticker, contract_type=client.Options.ContractType.ALL, strike_count=40, include_underlying_quote=True, strategy=client.Options.Strategy.SINGLE, from_date=exp_from, to_date=exp_to)`
  - `exp_from = (date.today() + timedelta(days=min_dte)).isoformat()`
  - `exp_to = (date.today() + timedelta(days=max_dte)).isoformat()`
- Parse the JSON response. The Schwab chain response has structure: `{"callExpDateMap": {...}, "putExpDateMap": {...}, "underlying": {...}}`
- Convert each expiration's calls and puts into pandas DataFrames with columns: `strike`, `bid`, `ask`, `mark`, `delta`, `gamma`, `theta`, `vega`, `impliedVolatility`, `openInterest`, `totalVolume`, `daysToExpiration`
- Return dict: `{"underlying_price": float, "expirations": [{"date": str, "dte": int, "calls": DataFrame, "puts": DataFrame}, ...], "ticker": ticker}`
- Rate limiting: track last request time in module-level `_last_request_time`; enforce minimum 0.6 second gap between requests (100 req/min = 1 per 0.6s); sleep if needed
- On `httpx.HTTPStatusError` 429: sleep 30 seconds, retry once
- On any other exception: log error, return `None` (do not propagate)
- Cache only on successful parse (non-empty expirations)

Imports needed: `schwab`, `pandas`, `os`, `time`, `logging`, `datetime`, `pathlib.Path`, `cache.db.get_db`, `cache.db.TTL`.

Do not import anything Schwab-related at module level that would fail if schwab-py is not installed — guard with try/except ImportError and set `schwab = None` if import fails, then `get_schwab_client()` returns None.

  <files>

  <action>
Create `data/edgar_fetcher.py`. Uses SEC EDGAR's public XBRL API (no auth required, rate limit: 10 req/sec).

**EDGAR API endpoint**: `https://data.sec.gov/api/xbrl/companyfacts/{CIK}.json`
**CIK lookup endpoint**: `https://efts.sec.gov/LATEST/search-index?q=%22{ticker}%22&dateRange=custom&startdt=2020-01-01&forms=10-K`
  - Alternative (simpler): SEC provides a bulk ticker-to-CIK mapping at `https://www.sec.gov/files/company_tickers.json` — download and cache this entire mapping once (TTL: 86400 × 7, one week)

**Headers required**: `{"User-Agent": "VRP Options Screener personal-use@local.dev"}` — SEC requires a descriptive User-Agent; without it requests are rejected.

**`_get_cik_map() -> dict[str, str]`** (private, cached):
- Cache key: `"edgar_cik_map_global"`
- TTL: 604800 (7 days)
- Fetch `https://www.sec.gov/files/company_tickers.json`
- Returns `{"AAPL": "0000320193", "MSFT": "0000789019", ...}` (ticker → zero-padded 10-digit CIK)
- Parse the SEC response which is `{0: {"cik_str": int, "ticker": str, "title": str}, 1: ...}`
- Build reverse map: `{entry["ticker"].upper(): str(entry["cik_str"]).zfill(10) for entry in data.values()}`
- Cache the result

**`fetch_edgar_financials(ticker: str) -> dict`**:
- Cache key: `f"{ticker.upper()}_edgar_{date.today().isoformat()}"`
- TTL: `TTL["fundamentals"]` (86400 seconds)
- If cache hit: return cached dict
- Lookup CIK from `_get_cik_map()`. If not found: return `{}` (ETFs, foreign companies not in EDGAR)
- Fetch `https://data.sec.gov/api/xbrl/companyfacts/{CIK}.json` — this returns ALL XBRL facts for the company
- Extract the most recent annual (10-K) and the most recent quarterly (10-Q) values for:
  - `us-gaap:Revenues` or `us-gaap:RevenueFromContractWithCustomerExcludingAssessedTax` → `revenue`
  - `us-gaap:NetIncomeLoss` → `net_income`
  - `us-gaap:NetCashProvidedByUsedInOperatingActivities` → `cfo`
  - `us-gaap:LongTermDebt` + `us-gaap:ShortTermBorrowings` → `total_debt` (sum both; use whichever are available)
  - Compute `fcf = cfo - capex` where `capex = abs(us-gaap:PaymentsToAcquirePropertyPlantAndEquipment)`
  - `us-gaap:Assets` → `total_assets`
  - `us-gaap:StockholdersEquity` or `us-gaap:RetainedEarningsAccumulatedDeficit` → `book_value`
  - `us-gaap:InterestExpense` → `interest_expense`
  - `us-gaap:CommonStockSharesOutstanding` → `shares_outstanding`

Helper `_latest_annual_value(facts, concept) -> Optional[float]`:
- `facts["us-gaap"][concept]["units"]["USD"]` → list of filings
- Filter to `form in ("10-K", "10-K/A")`, get the one with the most recent `end` date
- Return the `val` field as float

Return dict:
```python
{
    "ticker": ticker,
    "cik": cik,
    "revenue": float or None,
    "net_income": float or None,
    "cfo": float or None,
    "fcf": float or None,
    "total_debt": float or None,
    "total_assets": float or None,
    "book_value": float or None,
    "interest_expense": float or None,
    "shares_outstanding": float or None,
    "fiscal_year_end": str or None,  # "2024-09-30" format
}
```

Rate limiting: `time.sleep(0.15)` between each EDGAR request (enforces ~6.7 req/sec, within 10 req/sec limit with margin).

On any exception (KeyError from unexpected XBRL structure, network error, etc.): log error, return `{}`.

ETFs (like SPY) will not be in EDGAR — return `{}` gracefully.
