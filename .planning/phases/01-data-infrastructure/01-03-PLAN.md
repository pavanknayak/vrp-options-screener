  <action>
Create `data/yfinance_fetcher.py`. All functions follow the same pattern: check cache first, return if fresh, fetch and store if stale.

Cache key convention: `f"{ticker.upper()}_{data_type}_{date.today().isoformat()}"` — date suffix prevents stale keys surviving midnight across days without also triggering TTL expiry.

**`fetch_ohlcv(ticker: str, period_days: int = 252) -> pd.DataFrame`**
- Cache key: `f"{ticker.upper()}_ohlcv_{date.today().isoformat()}"`
- TTL: `TTL["ohlcv_history"]` (3600 seconds)
- If cache hit: log `f"[CACHE HIT] ohlcv {ticker}"`, return cached DataFrame
- If cache miss: log `f"[CACHE MISS] ohlcv {ticker} — fetching yfinance"`
- Fetch: `yf.Ticker(ticker).history(period="1y", interval="1d", auto_adjust=True)`
- If result is empty or has fewer than 50 rows: raise `ValueError(f"Insufficient OHLCV data for {ticker}: {len(df)} rows")`
- Normalize columns to `['Open','High','Low','Close','Volume']` (drop Dividends/Stock Splits if present)
- Return the last `period_days` rows

**`fetch_earnings_date(ticker: str) -> Optional[date]`**
- Cache key: `f"{ticker.upper()}_earnings_{date.today().isoformat()}"`
- TTL: `TTL["earnings_dates"]` (43200 seconds)
- Fetch: `yf.Ticker(ticker).calendar` — access `.get('Earnings Date')` key; it may return a list of dates (take the first future one)
- If no earnings date found, return `None` (do not raise)
- Return as `datetime.date` object

**`fetch_yf_options_summary(ticker: str) -> dict`**
- Cache key: `f"{ticker.upper()}_yf_options_{date.today().isoformat()}"`
- TTL: `TTL["options_chain_yf"]` (1800 seconds)
- Purpose: Used in Stage 1 bulk pre-filter for approximate IV and OI
- Fetch the nearest available expiration: `tk = yf.Ticker(ticker); exps = tk.options; if not exps: return {}`
- Get the nearest expiration options chain: `chain = tk.option_chain(exps[0])`
- Find ATM strike (closest to current price from `tk.fast_info['last_price']` or `tk.info.get('regularMarketPrice')`)
- Return dict: `{"atm_iv": float, "atm_oi": int, "expiration": str, "bid_ask_pct": float}`
  - `atm_iv`: `calls.loc[atm_idx, 'impliedVolatility']` (annualized, already as decimal)
  - `atm_oi`: `calls.loc[atm_idx, 'openInterest']`
  - `bid_ask_pct`: `(calls.loc[atm_idx, 'ask'] - calls.loc[atm_idx, 'bid']) / ((calls.loc[atm_idx, 'ask'] + calls.loc[atm_idx, 'bid']) / 2)`
  - On any exception (yfinance returns partial data frequently): log warning and return `{}`

**Error handling**: Wrap all yfinance calls in try/except. On `Exception`, log `f"[ERROR] yfinance fetch failed for {ticker}: {e}"` and return the empty/None sentinel (do not propagate exceptions — callers handle missing data gracefully).

Use `logging.getLogger(__name__)` throughout. Do NOT use `print()`.

Create `data/fred_fetcher.py`. Reads the FRED API key from the environment variable `FRED_API_KEY` (fall back to None if not set, in which case fetching is skipped and cached data is returned if available, else `None` is returned — do not raise).

Use `fredapi.Fred` client.

**`fetch_fred_rate(series_id: str = "DGS3MO") -> Optional[float]`**
- Cache key: `f"fred_{series_id}_{date.today().isoformat()}"`
- TTL: `TTL["fred_rates"]` (21600 seconds)
- If cache hit: return cached float
- If cache miss and no API key: log warning, return `None`
- Fetch: `fred = Fred(api_key=FRED_API_KEY); series = fred.get_series(series_id, observation_start=..., observation_end=date.today())`
  - Get the last non-NaN value
  - The value is in percent (e.g. 5.25 for 5.25%) — divide by 100 to return as decimal (0.0525)
- Cache and return the float
- On error: log `f"[ERROR] FRED fetch failed for {series_id}: {e}"`, return `None`

**`fetch_vix_history(lookback_days: int = 252) -> Optional[pd.Series]`**
- Cache key: `f"fred_VIXCLS_{date.today().isoformat()}"`
- TTL: `TTL["fred_rates"]` (21600)
- Fetch series `"VIXCLS"` (daily VIX close) for the past `lookback_days` calendar days
- Return as `pd.Series` with datetime index, float values
- Drop NaN values before returning
- On error or missing API key: return `None`

**`get_risk_free_rate() -> float`**
- Convenience function: calls `fetch_fred_rate("DGS3MO")`
- If result is None: return `0.05` as a safe default (log that default is being used)

Store `FRED_API_KEY = os.environ.get("FRED_API_KEY")` at module level.
Use `logging.getLogger(__name__)` throughout.
