Create `cache/` as a Python package. Create `cache/db.py` implementing a thread-safe SQLite TTL cache.

Schema (create on first connection if not exists):
```sql
CREATE TABLE IF NOT EXISTS cache (
    key TEXT PRIMARY KEY,
    value BLOB NOT NULL,
    fetched_at REAL NOT NULL,
    ttl_seconds INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_fetched_at ON cache(fetched_at);
```

Database file path: `vrp_cache.db` in the project root (resolved relative to this file's parent's parent, so `Path(__file__).parent.parent / "vrp_cache.db"`).

Implement `CacheDB` class with:
- `__init__(self, db_path: Path = None)` — creates parent dirs if needed, initializes schema
- `set(self, key: str, value: Any, ttl_seconds: int) -> None` — serialize value with `pickle.dumps()`, store with `fetched_at=time.time()`
- `get(self, key: str) -> Optional[Any]` — return `None` if key not found OR if `time.time() - fetched_at > ttl_seconds`; else deserialize with `pickle.loads()`
- `delete(self, key: str) -> None` — remove single key
- `purge_expired(self) -> int` — delete all rows where expired, return count deleted
- `exists(self, key: str) -> bool` — True if key exists AND not expired

Use `threading.Lock` for all write operations (SQLite WAL mode enabled: `PRAGMA journal_mode=WAL`).

TTL constants (define at top of file as module-level dict `TTL`):
```python
TTL = {
    "ohlcv_history": 3600,
    "options_chain_live": 900,
    "options_chain_yf": 1800,
    "fundamentals": 86400,
    "fred_rates": 21600,
    "earnings_dates": 43200,
}
```

Module-level singleton `get_db() -> CacheDB` using `functools.lru_cache(maxsize=1)`.

`cache/__init__.py` exports: `CacheDB`, `get_db`, `TTL`.

Do NOT use SQLAlchemy ORM for this — raw `sqlite3` is simpler and sufficient for a key-value store.

```python
FOMC_DATES = [
    # 2025
    "2025-01-29", "2025-03-19", "2025-05-07", "2025-06-18",
    "2025-07-30", "2025-09-17", "2025-10-29", "2025-12-10",
    # 2026
    "2026-01-28", "2026-03-18", "2026-04-29", "2026-06-17",
    "2026-07-29", "2026-09-16", "2026-10-28", "2026-12-09",
]
```

Implement `fomc_context(today: date, expiration_date: date) -> tuple[str, str]` returning `(status, message)`:
- Check every FOMC date. Convert to `datetime.date` for comparison.
- If `0 < (fomc_date - today).days <= 2`: return `("AVOID", f"FOMC in {days} days. High event risk. Wait for post-FOMC entry.")`
- If `(today - fomc_date).days == 1`: return `("PRIORITY_ENTRY", "FOMC concluded yesterday. Vol crush likely in progress. Prime entry window.")`
- If `today < fomc_date < expiration_date`: return `("FOMC_IN_WINDOW", f"FOMC on {fomc_date} falls within this expiration window. Moderate event risk.")`
- After checking all dates with no hit: return `("CLEAR", "No FOMC meeting in expiration window.")`

Priority order: AVOID > PRIORITY_ENTRY > FOMC_IN_WINDOW > CLEAR (check in that order; return first match).

`data/__init__.py` exports: nothing initially (modules imported directly).

No external dependencies — pure stdlib (datetime only).
