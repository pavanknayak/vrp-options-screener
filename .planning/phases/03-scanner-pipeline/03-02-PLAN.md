**Module-level constants:**
```python
_RATE_LIMIT_GAP = 0.6   # 100 req/min = 1 req per 0.6s
_last_schwab_call: float = 0.0
```

**Rate-limit enforcer (module-level, NOT inside stage2 — called before every Schwab request):**
```python
def _schwab_wait() -> None:
    global _last_schwab_call
    elapsed = time.time() - _last_schwab_call
    if elapsed < _RATE_LIMIT_GAP:
        time.sleep(_RATE_LIMIT_GAP - elapsed)
    _last_schwab_call = time.time()
```

Note: schwab_client.py already has its own `_enforce_rate_limit()` inside `fetch_options_chain`. The `_schwab_wait()` here is an outer guard at the stage2 loop level to prevent concurrent calls from different threads overwhelming the inner guard. Stage 2 is intentionally sequential (not threaded) to honour the 100 req/min budget.

**`_analyze_one(ticker: str, r: float, vix: float) -> dict` helper:**
1. `_schwab_wait()`
2. Fetch OHLCV: `ohlc = fetch_ohlcv(ticker)`. If empty, return `{"ticker": ticker, "error": "ohlcv_unavailable"}`.
3. Fetch Schwab chain with 429 retry:
   ```python
   chain = fetch_options_chain(ticker, min_dte=25, max_dte=55)
   if chain is None:
       # One retry after 60s (handles upstream 429 from schwab_client)
       logger.warning("[STAGE2] %s — chain is None, sleeping 60s and retrying", ticker)
       time.sleep(60)
       chain = fetch_options_chain(ticker, min_dte=25, max_dte=55)
   if chain is None:
       return {"ticker": ticker, "error": "schwab_chain_unavailable"}
   ```
4. Call `run_analytics(ticker, chain, ohlc, r, vix)` — it never raises, returns dict with possible 'error' key.
5. Return the result dict.

**`run_stage2(candidates: list, r: Optional[float] = None, vix: Optional[float] = None) -> list[dict]`:**

`candidates` is a list of objects with a `.ticker` attribute (Stage1Result instances), or plain dicts with "ticker" key, or bare ticker strings. Handle all three:
```python
def _get_ticker(c) -> str:
    if isinstance(c, str):
        return c
    if isinstance(c, dict):
        return c["ticker"]
    return c.ticker
```

Implementation:
1. If r is None: `r = get_risk_free_rate()`
2. If vix is None: `vix = _get_current_vix()`  (see below)
3. Log: `logger.info("[STAGE2] Starting Stage 2: %d candidates", len(candidates))`
4. t_start = time.time()
5. results = []
6. For each candidate in candidates (sequential — NOT threaded):
   - ticker = _get_ticker(candidate)
   - result = _analyze_one(ticker, r, vix)
   - results.append(result)
   - If result.get("error"): `logger.warning("[STAGE2] %s error: %s", ticker, result["error"])`
   - else: `logger.debug("[STAGE2] %s score=%.1f", ticker, result.get("composite_score", 0))`
7. Filter errors: `good = [r for r in results if not r.get("error")]`
8. Sort: `good.sort(key=lambda r: r.get("composite_score", 0.0), reverse=True)`
9. elapsed = time.time() - t_start
10. Log: `logger.info("[STAGE2] Complete in %.1fs — %d results, %d errors", elapsed, len(good), len(results) - len(good))`
11. Return good (errored tickers excluded from final output, already logged)

**`_get_current_vix() -> float` helper:**
```python
def _get_current_vix() -> float:
    try:
        vix_hist = fetch_vix_history(lookback_days=5)
        if vix_hist is not None and not vix_hist.empty:
            return float(vix_hist.iloc[-1])
    except Exception:
        pass
    return 20.0  # fallback
```

**`run_quick_refresh(prev_results: list[dict], top_n: int = 30, r: Optional[float] = None, vix: Optional[float] = None) -> list[dict]`:**

Takes the last full scan results list, slices the top_n by composite_score, and re-runs Stage 2 on just those tickers.

```python
def run_quick_refresh(
    prev_results: list[dict],
    top_n: int = 30,
    r: Optional[float] = None,
    vix: Optional[float] = None,
) -> list[dict]:
    logger.info("[QUICK_REFRESH] Re-analyzing top %d candidates", top_n)
    sorted_prev = sorted(prev_results, key=lambda r: r.get("composite_score", 0.0), reverse=True)
    top_tickers = [r["ticker"] for r in sorted_prev[:top_n]]
    return run_stage2(top_tickers, r=r, vix=vix)
```

**`run_single_ticker(ticker: str, r: Optional[float] = None, vix: Optional[float] = None) -> dict`:**

Runs Stage 2 on a single ticker and returns the single result dict (or error dict).

```python
def run_single_ticker(
    ticker: str,
    r: Optional[float] = None,
    vix: Optional[float] = None,
) -> dict:
    ticker = ticker.upper().strip()
    logger.info("[SINGLE_TICKER] Analyzing %s", ticker)
    results = run_stage2([ticker], r=r, vix=vix)
    if results:
        return results[0]
    return {"ticker": ticker, "error": "no_result"}
```

**`check_vix_event_trigger(threshold_pct: float = 5.0) -> bool`:**

Returns True if VIX has risen >= threshold_pct intraday (today's latest vs the prior close).

```python
def check_vix_event_trigger(threshold_pct: float = 5.0) -> bool:
    try:
        vix_hist = fetch_vix_history(lookback_days=5)
        if vix_hist is None or len(vix_hist) < 2:
            return False
        prior_close = float(vix_hist.iloc[-2])
        current = float(vix_hist.iloc[-1])
        rise_pct = (current - prior_close) / prior_close * 100.0
        triggered = rise_pct >= threshold_pct
        if triggered:
            logger.warning("[EVENT_REFRESH] VIX event triggered: %.1f%% rise (%.1f -> %.1f)", rise_pct, prior_close, current)
        return triggered
    except Exception as exc:
        logger.error("[EVENT_REFRESH] VIX check failed: %s", exc)
        return False
```

**`run_event_refresh(prev_results: list[dict], top_n: int = 50, r: Optional[float] = None, vix: Optional[float] = None) -> list[dict]`:**

Re-runs Stage 2 on top 50 when VIX has risen >= 5% intraday.

def run_event_refresh(
