**Stage1Result dataclass:**
```python
@dataclass
class Stage1Result:
    ticker: str
    tier: str
    asset_class: str
    score: float          # IVP * max(VRP_approx, 0)
    ivp_approx: float     # percentile of atm_iv in 30-day ohlcv-derived vol
    vrp_approx: float     # atm_iv - realized_vol_30d_approx
    atm_iv: float
    earnings_date: Optional[date]
    skip_reason: Optional[str]   # non-None means ticker was skipped
```

**Per-ticker worker function `_score_ticker(ticker: str, info: TickerInfo, min_dte: int, max_dte: int) -> Stage1Result`:**

Steps (all inside try/except — return Stage1Result with skip_reason on any error):

1. Fetch OHLCV: `ohlc = fetch_ohlcv(ticker)`. If empty DataFrame, return skip with reason "ohlcv_unavailable".

2. Fetch earnings: `earnings = fetch_earnings_date(ticker)`. Check earnings filter:
   - Compute today = date.today()
   - dte_window_start = today + timedelta(days=min_dte)
   - dte_window_end = today + timedelta(days=max_dte)
   - If earnings is not None AND dte_window_start <= earnings <= dte_window_end:
     - Log at WARNING: `logger.warning("[STAGE1 SKIP] %s — earnings %s inside DTE window %d-%d", ticker, earnings, min_dte, max_dte)`
     - Return Stage1Result with skip_reason=f"earnings_in_window:{earnings}"

3. Fetch yfinance options summary: `yf_opts = fetch_yf_options_summary(ticker)`. If empty dict, return skip with reason "options_unavailable".

4. Apply liquidity gate from TickerInfo.options_filter:
   - `atm_bid_ask_max = info.options_filter.get("atm_bid_ask_max_pct", 0.50)` (default 50% — generous for pre-filter)
   - `min_oi = info.options_filter.get("min_oi", 10)` (default 10)
   - If yf_opts["bid_ask_pct"] > atm_bid_ask_max: skip with reason "bid_ask_too_wide"
   - If yf_opts["atm_oi"] < min_oi: skip with reason "insufficient_oi"

5. Approximate IVP and VRP:
   - `atm_iv = yf_opts["atm_iv"]`
   - Compute 30-day realized vol from OHLCV close returns:
     ```python
     closes = ohlc["Close"].dropna()
     if len(closes) < 31:
         return Stage1Result(..., skip_reason="insufficient_history")
     log_rets = closes.pct_change().dropna()
     realized_30d = float(log_rets.tail(21).std() * math.sqrt(252))
     ```
   - `vrp_approx = atm_iv - realized_30d`
   - IVP approximation: compute rolling 252-day annualized vols from log returns, rank atm_iv in that distribution:
     ```python
     rolling_stds = log_rets.rolling(21).std().dropna() * math.sqrt(252)
     ivp_approx = float((rolling_stds < atm_iv).mean()) if len(rolling_stds) > 10 else 0.5
     ```
   - `score = ivp_approx * max(vrp_approx, 0.0)`

6. Return Stage1Result(ticker=ticker, tier=info.tier, asset_class=info.asset_class, score=score, ivp_approx=ivp_approx, vrp_approx=vrp_approx, atm_iv=atm_iv, earnings_date=earnings, skip_reason=None)

**run_stage1() function:**
```python
def run_stage1(
    universe: Optional[dict] = None,
    n_workers: int = 20,
    top_n: int = 175,
    min_dte: int = 25,
    max_dte: int = 55,
    per_ticker_timeout: float = 8.0,
) -> list[Stage1Result]:
```

Implementation:
1. If universe is None: `universe = load_universe()`
2. Log: `logger.info("[STAGE1] Starting Stage 1 scan: %d tickers, %d workers", len(universe), n_workers)`
3. `t_start = time.time()`
4. results: list[Stage1Result] = []
5. Use ThreadPoolExecutor(max_workers=n_workers) as executor:
   - Submit one future per ticker: `future_to_ticker = {executor.submit(_score_ticker, ticker, info, min_dte, max_dte): ticker for ticker, info in universe.items()}`
   - Collect with as_completed() and per-future timeout:
     ```python
     for future in as_completed(future_to_ticker, timeout=None):
         ticker = future_to_ticker[future]
         try:
             result = future.result(timeout=per_ticker_timeout)
             results.append(result)
         except FuturesTimeoutError:
             logger.warning("[STAGE1 TIMEOUT] %s exceeded %.1fs", ticker, per_ticker_timeout)
             results.append(Stage1Result(ticker=ticker, tier="?", asset_class="?", score=0.0, ivp_approx=0.0, vrp_approx=0.0, atm_iv=0.0, earnings_date=None, skip_reason="timeout"))
         except Exception as exc:
             logger.error("[STAGE1 ERROR] %s: %s", ticker, exc)
             results.append(Stage1Result(ticker=ticker, tier="?", asset_class="?", score=0.0, ivp_approx=0.0, vrp_approx=0.0, atm_iv=0.0, earnings_date=None, skip_reason=f"error:{exc}"))
     ```
6. Filter to non-skipped results: `candidates = [r for r in results if r.skip_reason is None]`
7. Sort descending by score: `candidates.sort(key=lambda r: r.score, reverse=True)`
8. Top N: `top = candidates[:top_n]`
9. elapsed = time.time() - t_start
10. Log summary: `logger.info("[STAGE1] Complete in %.1fs — %d candidates (from %d scored, %d skipped)", elapsed, len(top), len(candidates), len(results) - len(candidates))`
11. Return top

Do NOT use `executor.map()` — use `as_completed()` so individual ticker timeouts do not block the entire scan.
