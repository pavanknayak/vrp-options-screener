**Dataclasses:**
```python
@dataclass
class ScenarioPnL:
    name: str        # "Bull" | "Base" | "Bear" | "Crash"
    underlying_move: float   # e.g. +0.15, 0.0, -0.10, -0.25
    terminal_price: float    # spot * (1 + underlying_move)
    pnl_per_contract: float  # P&L in dollars for 1 contract (100 shares)
    probability: float       # scenario probability [0.0, 1.0]
    weighted_pnl: float      # pnl_per_contract * probability

@dataclass
class PnLResult:
    net_credit: float              # credit received per contract (dollars)
    max_loss: float                # maximum loss per contract (dollars, positive number)
    breakeven: float               # breakeven underlying price
    profit_target: float           # 50% of max profit = net_credit * 0.50
    hard_stop: float               # 200% of net_credit loss (2× credit received)
    roll_trigger: float            # underlying falls to breakeven * 0.97
    scenarios: list[ScenarioPnL]   # 4 scenarios in order: Bull, Base, Bear, Crash
    probability_weighted_ev: float # sum(s.weighted_pnl for s in scenarios)
    slippage_adj_ev: float         # EV after slippage adjustment (per contract, dollars)
    kelly_dollars: float           # position size in dollars
    kelly_contracts: int           # floor(kelly_dollars / (100 * spot))
    kelly_pct: float               # kelly_dollars / portfolio_value
    kelly_breakdown: dict          # {"base": 0.25, "regime_mult": x, "vov_mult": x, "gex_mult": x, "final_f": x}
```

---

**compute_slippage_ev(bid: float, ask: float) -> float:**

Returns per-leg slippage-adjusted credit:
```python
mid = (bid + ask) / 2.0
return mid * 0.75  # 75% of mid captures realistic fill
```

---

**compute_pnl_scenarios(structure_result, chain, analytics_result) -> tuple[list[ScenarioPnL], float, float, float, float, float, float]:**

Returns: `(scenarios, net_credit, max_loss, breakeven, profit_target, hard_stop, roll_trigger)`

Step 1 — Determine asset class and scenario parameters:
```python
asset_class = analytics_result.get("asset_class", "us_equity")
is_crypto = asset_class == "crypto_etf"

if is_crypto:
    moves = {"Bull": +0.50, "Base": 0.0, "Bear": -0.30, "Crash": -0.50}
    probs = {"Bull": 0.25, "Base": 0.40, "Bear": 0.20, "Crash": 0.15}
else:
    moves = {"Bull": +0.15, "Base": 0.0, "Bear": -0.10, "Crash": -0.25}
    probs = {"Bull": 0.25, "Base": 0.45, "Bear": 0.20, "Crash": 0.10}
```

Step 2 — Extract contract prices from chain for the selected expiration:

Find the expiration in chain matching structure_result.dte (closest dte match):
```python
expirations = chain.get("expirations", [])
exp = min(expirations, key=lambda e: abs(e.get("dte", 999) - structure_result.dte))
puts_df = exp.get("puts", pd.DataFrame())
calls_df = exp.get("calls", pd.DataFrame())
```

For **CSP**: find put row with strike == structure_result.short_strike (or nearest). Extract `bid` and `ask`. Compute:
```python
net_credit = compute_slippage_ev(bid, ask)   # per-share credit
net_credit_contract = net_credit * 100        # per-contract
max_loss = (structure_result.short_strike - net_credit) * 100  # max loss if put exercised to zero
breakeven = structure_result.short_strike - net_credit
```

For **Spread**: find short put (short_strike) and long put (long_strike). Net credit = slippage_ev(short bid, short ask) - slippage_ev(long ask, long bid) [sell short, buy long].
```python
spread_width = structure_result.short_strike - structure_result.long_strike
net_credit = short_ev - long_ev   # per share
net_credit_contract = net_credit * 100
max_loss = (spread_width - net_credit) * 100
breakeven = structure_result.short_strike - net_credit
```

Step 3 — P&L per scenario per contract:

For **CSP**:
- Bull (underlying up): put expires worthless → `pnl = net_credit_contract`
- Base (flat): put expires worthless → `pnl = net_credit_contract`
- Bear (underlying -10%): terminal_price = spot * (1 + move). If terminal_price >= short_strike: full credit. Else: `pnl = (terminal_price - short_strike + net_credit) * 100` (capped at net_credit on upside, max_loss on downside).
- Crash: same formula as Bear.

For **Spread**:
- Bull/Base: full credit (both puts expire worthless if terminal > short_strike)
- Bear: `pnl = max(-max_loss, min(net_credit_contract, (terminal_price - short_strike + net_credit) * 100))`
- Crash: same as Bear but even lower terminal_price. Spread can never lose more than `max_loss`.

Step 4 — Compute weighted EV:
```python
scenarios_out = []
for name in ("Bull", "Base", "Bear", "Crash"):
    terminal = spot * (1 + moves[name])
    pnl = _pnl_for_scenario(structure, short_strike, long_strike, terminal, net_credit, max_loss, net_credit_contract)
    s = ScenarioPnL(name=name, underlying_move=moves[name], terminal_price=terminal,
                    pnl_per_contract=pnl, probability=probs[name], weighted_pnl=pnl * probs[name])
    scenarios_out.append(s)

weighted_ev = sum(s.weighted_pnl for s in scenarios_out)
```

Step 5 — Trade management levels:
```python
profit_target = net_credit_contract * 0.50       # close at 50% of max profit
hard_stop = net_credit_contract * 2.0            # close if loss = 2× credit
roll_trigger = breakeven * 0.97                  # roll if underlying drops 3% below breakeven
```

Return all values. Use `net_credit_contract` as `slippage_adj_ev` for the go/no-go check.

**compute_kelly_size(analytics_result, ticker_info, pnl_result, portfolio_value) -> tuple[float, int, float, dict]:**

Returns: `(kelly_dollars, kelly_contracts, kelly_pct, kelly_breakdown)`

```python
regime = analytics_result.get("regime", {})
regime_mult = float(regime.get("multiplier", 1.0))

vov_z = analytics_result.get("signals", {}).get("vov_z", 0.0)
vov_mult = 0.75 if vov_z > 1.5 else 1.0

gex_bn = analytics_result.get("gex_billions", 0.0)
gex_mult = 0.75 if gex_bn < 0 else 1.0

base_f = 0.25
final_f = base_f * regime_mult * vov_mult * gex_mult

max_pos = ticker_info.max_position_pct          # e.g. 0.05 for equity, 0.02 for crypto
min_pos = max_pos / 4.0

kelly_pct = float(np.clip(final_f * max_pos, min_pos, max_pos))
kelly_dollars = kelly_pct * portfolio_value
spot = analytics_result.get("spot", 100.0)   # get from chain if available
kelly_contracts = max(1, int(kelly_dollars / (100.0 * spot))) if spot > 0 else 1

breakdown = {
    "base": base_f,
    "regime_mult": regime_mult,
    "vov_mult": vov_mult,
    "gex_mult": gex_mult,
    "final_f": final_f,
    "kelly_pct": kelly_pct,
}
return kelly_dollars, kelly_contracts, kelly_pct, breakdown
```
