Output: `recommendations/gonogo.py` with `evaluate_gonogo()` and a `GoNoGoResult` dataclass. `recommendations/__init__.py` as the package marker.

**GoNoGoResult dataclass** (use `dataclasses.dataclass`):
```python
@dataclass
class GoNoGoResult:
    passed: bool                      # True only if all 21 checks pass
    failed_criterion: str | None      # First failing criterion ID (e.g. "HARD-04")
    failed_reason: str | None         # Human-readable explanation of the failure
    permitted_structures: list[str]   # Forwarded from fundamentals gate_result
    checks: list[dict]                # All checks with {"id", "name", "passed", "reason"}
```

**evaluate_gonogo()** signature:
```python
def evaluate_gonogo(
    analytics_result: dict,       # from run_analytics()
    fundamentals_result: dict,    # from run_fundamentals()
    ticker_info,                  # TickerInfo dataclass
    proposed_structure: str,      # "csp" | "spread" | "collar" (pre-computed by structures.py)
    slippage_adj_ev: float,       # pre-computed slippage-adjusted EV (from pnl.py)
) -> GoNoGoResult:
```

**The 21 checks in order** — evaluation stops at first failure:

HARD disqualifiers (checks 1–9):
1. ID="HARD-01", name="VRP Statistical Significance": FAIL if `analytics_result.get("vrp_pctile", 0) < 0.40`. Reason: "VRP at {vrp_pctile*100:.0f}th percentile — below 40th percentile threshold."
2. ID="HARD-02", name="Earnings Inside DTE Window": FAIL if `analytics_result.get("has_earnings_in_window", False)` is True. Reason: "Earnings fall within the option expiration window — binary event risk."
3. ID="HARD-03", name="Slippage-Adjusted EV Positive": FAIL if `slippage_adj_ev <= 0`. Reason: "Slippage-adjusted EV is {slippage_adj_ev:.4f} — non-positive expected value."
4. ID="HARD-04", name="VoV Z-Score Stability": FAIL if `analytics_result.get("signals", {}).get("vov_z", 0) > 2.5`. Reason: "VoV Z-score {vov_z:.2f} exceeds 2.5 — IV too unstable to collect premium."
5. ID="HARD-05", name="Regime Not Crisis": FAIL if `analytics_result.get("regime_label", "") == "Crisis"`. Reason: "Crisis regime detected (VIX > 40). No new short-vol positions."
6. ID="HARD-06", name="Altman Distress Gate": FAIL if `fundamentals_result.get("altman", {}).get("is_distress", False)` is True AND `ticker_info.requires_fundamental_score` is True. Reason: "Altman Z in distress zone (score={score}) — fundamental gate blocks CSP."
7. ID="HARD-07", name="Jump% Threshold": FAIL if `analytics_result.get("jump_pct", 0) > 0.50`. Reason: "Jump component {jump_pct*100:.1f}% of RV — above 50% threshold, diffusive VRP unreliable."
8. ID="HARD-08", name="China ADR Structure Ban": FAIL if `ticker_info.asset_class == "china_adr"` AND `proposed_structure == "csp"`. Reason: "China ADR (Tier 6B) CSP structurally banned — only Spread/Collar permitted."
9. ID="HARD-09", name="Crypto ETF Structure Ban": FAIL if `ticker_info.asset_class == "crypto_etf"` AND `proposed_structure == "csp"`. Reason: "Crypto ETF CSP structurally banned — only Spread/Collar permitted."

SOFT filters (checks 10–21):
10. ID="SOFT-01", name="Composite Score Minimum (Tier 1A-1I)": FAIL if tier starts with "1" AND `analytics_result.get("composite_score", 0) < 35`. Reason: "Composite score {score:.1f} below 35 minimum for ETF tier."
11. ID="SOFT-02", name="Composite Score Minimum (Tier 2)": FAIL if tier == "2" AND composite_score < 45. Reason: "Composite score {score:.1f} below 45 minimum for Tier 2."
12. ID="SOFT-03", name="Composite Score Minimum (Tier 3)": FAIL if tier == "3" AND composite_score < 50. Reason: "Composite score {score:.1f} below 50 minimum for Tier 3."
13. ID="SOFT-04", name="Composite Score Minimum (Tier 4/5)": FAIL if tier in ("4", "5") AND composite_score < 55. Reason: "Composite score {score:.1f} below 55 minimum for Tier 4/5."
14. ID="SOFT-05", name="Composite Score Minimum (ADR Tiers)": FAIL if tier in ("6A", "6B", "7") AND composite_score < 50. Reason: "Composite score {score:.1f} below 50 minimum for ADR tier."
15. ID="SOFT-06", name="IVP Minimum": FAIL if `analytics_result.get("ivp", 0) < 0.40`. Reason: "IVP {ivp*100:.0f}th percentile below 40th — IV not sufficiently elevated."
16. ID="SOFT-07", name="VRP Persistence": FAIL if `analytics_result.get("signals", {}).get("vrp_persist_30d", 0) < 0.50`. Reason: "VRP positive only {persist*100:.0f}% of last 30 days — premium insufficiently persistent."
17. ID="SOFT-08", name="Fundamental Gate": FAIL if `fundamentals_result.get("gate_result", {}).get("passed", True)` is False AND tier in ("3","4","5","6A","7"). Reason: "Fundamental gate failed: {failed_criterion}."
18. ID="SOFT-09", name="GEX Not Severely Negative": FAIL if `analytics_result.get("gex_billions", 0) < -2.0`. Reason: "GEX {gex:.2f}B — severely negative dealer positioning amplifies realized vol."
19. ID="SOFT-10", name="Term Structure Not Severely Inverted": FAIL if `analytics_result.get("signals", {}).get("term_slope", 0) < -0.05`. Reason: "Term structure deeply inverted ({slope*100:.1f}pp) — contango required for premium collection."
20. ID="SOFT-11", name="VoV Moderate Check": FAIL if `analytics_result.get("signals", {}).get("vov_z", 0) > 1.5` AND `analytics_result.get("regime_label", "") in ("Crisis", "High")`. Reason: "VoV Z {vov_z:.2f} elevated in High/Crisis regime — double vol-instability flag."
21. ID="SOFT-12", name="PCR Not Extreme Bearish": FAIL if `analytics_result.get("pcr_oi", 1.0) > 3.0`. Reason: "PCR OI {pcr:.2f} — extreme put-buying indicates hedger panic, not orderly premium."

**Implementation notes:**
- Build a list of all checks progressively. After each check, if not passed, set `passed=False`, record `failed_criterion` and `failed_reason`, and return immediately.
- `permitted_structures` comes from `fundamentals_result.get("gate_result", {}).get("permitted_structures", ["csp", "spread", "collar"])`.
- If `fundamentals_result` has an `"error"` key, treat fundamental checks as skipped (pass through) but log a warning.
- The function never raises; wrap body in try/except, returning GoNoGoResult(passed=False, failed_criterion="INTERNAL_ERROR", ...) on exception.
