**SUPPORTED_STRUCTURES constant (module-level):**
```python
SUPPORTED_STRUCTURES = {"csp", "spread", "collar"}
```
This constant is the source of truth for what Phase 5 implements. Any value from tickers.json's `permitted_structures` that is not in this set (e.g., "strangle", "condor") must be silently ignored.

**StructureResult dataclass:**
```python
@dataclass
class StructureResult:
    structure: str              # "csp" | "spread" | "collar"
    expiration_date: str        # ISO date string "YYYY-MM-DD"
    dte: int                    # actual DTE of selected expiration
    target_delta: float         # Kelly-optimal delta [0.10, 0.35]
    short_strike: float         # short put/call strike
    long_strike: float | None   # long put strike for spread/collar; None for CSP
    collar_call_strike: float | None  # short call strike for collar leg; None for CSP/Spread
    spot: float                 # underlying price at time of selection
    fomc_status: str            # "CLEAR" | "FOMC_IN_WINDOW" | "AVOID" | "PRIORITY_ENTRY"
    fomc_message: str           # human-readable fomc_context message
    delta_adjustment_reason: str  # explains why delta was shifted from 0.25
```

**select_structure(ticker_info, analytics_result) -> str:**

Logic for choosing among permitted_structures:
1. Get `raw_permitted = ticker_info.permitted_structures`.
2. **Filter to supported structures only:** `permitted = [s for s in raw_permitted if s in SUPPORTED_STRUCTURES]`
   — This silently drops "strangle" and "condor" if present in tickers.json. Do not log a warning unless `permitted` is empty after filtering.
3. If `"csp"` is in permitted AND `ticker_info.asset_class` not in `{"crypto_etf", "china_adr"}`: prefer `"csp"`.
4. Else if `"spread"` is in permitted: prefer `"spread"`.
5. Else if `"collar"` is in permitted: prefer `"collar"`.
6. If permitted is empty after filter: log a warning and return `"spread"` (safe fallback).

**select_strikes(analytics_result, ticker_info, chain, today_date) -> StructureResult:**

Step 1 — Compute target delta:
```python
base_delta = 0.25
vrp_pctile = analytics_result.get("vrp_pctile", 0.5)
vov_z = analytics_result.get("signals", {}).get("vov_z", 0.0)

reasons = []
if vrp_pctile > 0.80:
    base_delta = min(base_delta, 0.20)
    reasons.append("VRP at 80th+ pctile — tighter delta (0.20) to improve entry price")
if vov_z > 1.5:
    base_delta = min(base_delta, 0.20)
    reasons.append(f"VoV Z={vov_z:.2f} >1.5 — safer delta (0.20)")

target_delta = float(np.clip(base_delta, 0.10, 0.35))
delta_reason = "; ".join(reasons) if reasons else "Base 25Δ — no adjustment signals triggered"
```

Step 2 — Select expiration nearest to 45 DTE, then check FOMC:
```python
from datetime import date, timedelta
from data.fomc import fomc_context

expirations = chain.get("expirations", [])
# Sort by abs(dte - 45), pick nearest
expirations_sorted = sorted(expirations, key=lambda e: abs(e.get("dte", 999) - 45))

selected_exp = None
fomc_status = "CLEAR"
fomc_msg = ""
for exp in expirations_sorted:
    dte = exp.get("dte", 45)
    # Prefer the chain's stored date; fall back to arithmetic if absent
    if "date" in exp:
        exp_date = date.fromisoformat(exp["date"])
    else:
        exp_date = today_date + timedelta(days=dte)
    status, msg = fomc_context(today_date, exp_date)
    if status == "AVOID":
        # Try next expiration in sorted list
        continue
    selected_exp = exp
    fomc_status = status
    fomc_msg = msg
    break

if selected_exp is None:
    # All expirations are AVOID — use the furthest-out one (least-bad)
    selected_exp = expirations_sorted[-1] if expirations_sorted else expirations[0]
    dte_used = selected_exp.get("dte", 45)
    if "date" in selected_exp:
        exp_date = date.fromisoformat(selected_exp["date"])
    else:
        exp_date = today_date + timedelta(days=dte_used)
    fomc_status, fomc_msg = fomc_context(today_date, exp_date)
```

Step 3 — Find strikes in selected expiration for the chosen structure:

The chain expiration has keys `"calls"` (DataFrame) and `"puts"` (DataFrame), each with columns: `strike`, `bid`, `ask`, `delta` (may be missing or None), `impliedVolatility`, `openInterest`.

For **CSP**: find the put contract whose `|delta| - target_delta` is minimized. Use `abs()` since put deltas are negative in the chain.
```python
puts_df = selected_exp.get("puts", pd.DataFrame())
if "delta" in puts_df.columns and not puts_df["delta"].isna().all():
    # Find put closest to -target_delta (use abs since put deltas are negative)
    valid_puts = puts_df.dropna(subset=["delta"])
    idx = (valid_puts["delta"].abs() - target_delta).abs().idxmin()
    short_strike = float(valid_puts.loc[idx, "strike"])
    long_strike = None
    collar_call_strike = None
else:
    # Fallback: use BSM approximate delta strike
    # K = S * exp(N^{-1}(target_delta) * iv * sqrt(T))
    spot = chain.get("underlying_price", 100.0)
    iv = analytics_result.get("iv30", 0.25)
    T = max(selected_exp.get("dte", 45) / 365.0, 1e-4)
    k_approx = spot * np.exp(norm.ppf(target_delta) * iv * np.sqrt(T))
    idx = (puts_df["strike"] - k_approx).abs().idxmin() if not puts_df.empty else None
    short_strike = float(puts_df.loc[idx, "strike"]) if idx is not None else round(spot * 0.90, 0)
    long_strike = None
    collar_call_strike = None
```

For **Spread**: short put at target_delta, long put 5 strikes lower (approximately $5 wide for stocks, 1% wide for high-priced stocks). Long strike = max(short_strike - spread_width, 0). Compute spread_width as `max(5.0, round(spot * 0.05 / 5) * 5)` for stocks under $100, or `round(spot * 0.025)` for stocks over $100 (round to nearest $5). Set `collar_call_strike = None`.

For **Collar**: implement put legs the same as Spread (short put at target_delta, long put at spread_width below). Additionally, select the short call strike from calls_df at 0.25-delta OTM:
```python
calls_df = selected_exp.get("calls", pd.DataFrame())
collar_call_strike = None
if not calls_df.empty and "delta" in calls_df.columns and not calls_df["delta"].isna().all():
    valid_calls = calls_df.dropna(subset=["delta"])
    # Call deltas are positive; find call closest to 0.25-delta OTM
    cidx = (valid_calls["delta"].abs() - 0.25).abs().idxmin()
    collar_call_strike = float(valid_calls.loc[cidx, "strike"])
else:
    # BSM fallback for call strike: K_call = S * exp(N^{-1}(1 - 0.25) * iv * sqrt(T))
    # = S * exp(N^{-1}(0.75) * iv * sqrt(T)) — OTM above spot
    if not calls_df.empty:
        k_call_approx = spot * np.exp(norm.ppf(0.75) * iv * np.sqrt(T))
        cidx = (calls_df["strike"] - k_call_approx).abs().idxmin()
        collar_call_strike = float(calls_df.loc[cidx, "strike"])
# Add "collar: includes short call at {collar_call_strike}" to delta_reason
if collar_call_strike:
    delta_reason += f"; collar: short call selected at {collar_call_strike:.1f} (0.25Δ OTM call)"
```

Step 4 — Assemble StructureResult:
```python
structure = select_structure(ticker_info, analytics_result)
spot = chain.get("underlying_price", 0.0)
exp_date_str = exp_date.isoformat()

return StructureResult(
    structure=structure,
    expiration_date=exp_date_str,
    dte=selected_exp.get("dte", 45),
    target_delta=target_delta,
    short_strike=short_strike,
    long_strike=long_strike,
    collar_call_strike=collar_call_strike,
    spot=spot,
    fomc_status=fomc_status,
    fomc_message=fomc_msg,
    delta_adjustment_reason=delta_reason,
)
```

**Error handling:** Wrap `select_strikes` body in try/except; on exception, return a StructureResult with `short_strike=round(spot * 0.90, 0)`, `long_strike=None`, `collar_call_strike=None`, `fomc_status="CLEAR"`, `fomc_message=""`, `delta_adjustment_reason="fallback: exception during selection"`.
