**RecommendationCard dataclass:**
```python
@dataclass
class RecommendationCard:
    ticker: str
    passed: bool                     # False if go/no-go failed (card still generated for UI display)
    gonogo_summary: str              # "PASS" | "FAIL: {criterion} — {reason}"
    gonogo_checks: list[dict]        # raw check list from GoNoGoResult

    # Trade parameters
    structure: str                   # "csp" | "spread" | "collar"
    expiration_date: str             # "YYYY-MM-DD"
    dte: int
    short_strike: float
    long_strike: float | None
    spot: float
    target_delta: float
    fomc_status: str
    fomc_message: str

    # Trade economics (per contract = 100 shares)
    net_credit: float                # dollars
    max_loss: float                  # dollars
    breakeven: float                 # underlying price
    profit_target: float             # dollars (50% of max profit)
    hard_stop: float                 # dollars (2× credit)
    roll_trigger: float              # underlying price

    # P&L scenarios
    scenarios: list                  # list[ScenarioPnL]
    probability_weighted_ev: float   # dollars
    slippage_adj_ev: float           # dollars

    # Position sizing
    kelly_dollars: float
    kelly_contracts: int
    kelly_pct: float
    kelly_breakdown: dict

    # Narratives
    paragraph_1: str                 # Why premium exists
    paragraph_2: str                 # Why to enter now vs wait
    paragraph_3: str                 # What could cause this trade to lose

    # Order text
    order_text: str                  # broker-ready instruction
```

---

**_build_paragraph_1(ticker, analytics_result, signals) -> str:**

Template (no generic boilerplate — every value must be interpolated):
```
"IV30 is at the {ivp_pct:.0f}th percentile of the past 252 days (IVP). "
"VRP is at the {vrp_pct:.0f}th percentile of history (+{vrp_ann:.1f}% annualized above realized vol). "
"The 25-delta skew is {skew_pct:.1f}% (put premium over call), indicating hedging demand. "
"VRP has been positive {persist_pct:.0f}% of the last 30 trading sessions (persistence). "
"Excess VRP above beta-adjusted SPY benchmark: +{excess_pct:.2f}% — suggesting idiosyncratic premium collection opportunity."
```

Interpolation keys:
- `ivp_pct = signals.get("ivp", 0.5) * 100`
- `vrp_pct = analytics_result.get("vrp_pctile", 0.5) * 100`
- `vrp_ann = analytics_result.get("vrp", 0.0) * 100`
- `skew_pct = signals.get("skew_25d", 0.0) * 100`
- `persist_pct = signals.get("vrp_persist_30d", 0.5) * 100`
- `excess_pct = signals.get("excess_vrp", 0.0) * 100`

---

**_build_paragraph_2(ticker, analytics_result, structure_result, signals) -> str:**

Template:
```
"Timing signal: {timing_action}. {timing_reason} "
"FOMC status: {fomc_status} — {fomc_message} "
"GEX is {gex_sign} at {gex:.2f}B ({gex_context}). "
"VoV Z-score is {vov_z:.2f} ({vov_flag_text}). "
"Term structure: {term_context}."
```

Interpolation:
- `timing_action = analytics_result.get("timing_action", "ENTER AT OPPORTUNITY")`
- `timing_reason = analytics_result.get("timing_reason", "")`
- `fomc_status = structure_result.fomc_status`
- `fomc_message = structure_result.fomc_message`
- `gex = signals.get("gex_billions", 0.0)`
- `gex_sign = "positive" if gex >= 0 else "negative"`
- `gex_context = "dealer gamma suppresses realized vol — supports premium collection" if gex >= 0 else "negative dealer gamma amplifies realized vol — use reduced size"`
- `vov_z = signals.get("vov_z", 0.0)`
- `vov_flag_text = "stable IV regime — full size" if vov_z <= 1.5 else f"elevated IV instability — size reduced by 25%"`
- `term_slope = signals.get("term_slope", 0.0)`
- `term_context = f"contango ({term_slope*100:.1f}pp) — normal structure supports premium collection" if term_slope >= 0 else f"backwardation ({term_slope*100:.1f}pp) — near-term stress, verify earnings calendar"`

---

**_build_paragraph_3(ticker, analytics_result, signals, fundamentals_result) -> str:**

Template — references specific risk factors, not generic:
```
"Primary risk: {primary_risk}. "
"Jump risk: {jump_text}. "
"Regime: {regime_label} ({regime_msg}). "
"This trade loses if {loss_condition}."
```

Interpolation:
- **Primary risk** — check in order:
  1. If `analytics_result.get("has_earnings_in_window")`: `f"EARNINGS inside DTE window — binary event, do not enter"`
  2. If `signals.get("jump_flag", "")`: use `signals["jump_flag"]` (already human-readable from vrp_engine.py)
  3. If `fundamentals_result.get("qoe", {}).get("accrual_anomaly", False)`: `"accrual anomaly detected (CFO/NI < 0.8) — earnings quality suspect"`
  4. Else: `f"macro correlation — if VIX spikes sharply, {ticker} short-vol loses regardless of individual signals"`

- `jump_text = f"jump component is {signals.get('jump_pct', 0)*100:.1f}% of RV — {'binary event risk elevated' if signals.get('jump_pct', 0) > 0.25 else 'diffusive vol dominates, clean VRP signal'}"`

- `regime_label = analytics_result.get("regime_label", "Normal")`
- `regime_msg = analytics_result.get("regime", {}).get("message", "")`

- **loss_condition** — based on structure:
  - CSP: `f"underlying {ticker} drops below ${structure_result.short_strike:.2f} (current: ${structure_result.spot:.2f}, distance: {(structure_result.spot - structure_result.short_strike)/structure_result.spot*100:.1f}%)"`
  - Spread: `f"underlying {ticker} drops below ${structure_result.short_strike:.2f} before expiration; max loss is ${pnl_result.max_loss:.0f}/contract"`

---

**_build_order_text(ticker, structure_result, pnl_result) -> str:**

Format varies by structure:

For **CSP**:
```
"STO {ticker} {exp_month} {short_strike:.0f}P at ${net_credit_per_share:.2f} credit"
"Max loss: ${max_loss:.0f}/contract | Breakeven: ${breakeven:.2f}"
```

For **Spread**:
```
"BTO {ticker} {exp_month} {long_strike:.0f}P / STO {ticker} {exp_month} {short_strike:.0f}P at ${net_credit_per_share:.2f} net credit"
"Max loss: ${max_loss:.0f}/contract | Breakeven: ${breakeven:.2f}"
```

Where `exp_month` is `structure_result.expiration_date` parsed to `"Mon DD"` format (e.g., `"Apr 21"`).
`net_credit_per_share = pnl_result.net_credit / 100` (since net_credit stored in dollars per contract).

---

**build_recommendation_card(ticker, analytics_result, fundamentals_result, ticker_info, chain, gonogo_result, structure_result, pnl_result) -> RecommendationCard:**

Assembles all fields:
1. Extract `signals = analytics_result.get("signals", {})`.
2. Set `passed = gonogo_result.passed`.
3. Set `gonogo_summary = "PASS" if passed else f"FAIL: {gonogo_result.failed_criterion} — {gonogo_result.failed_reason}"`.
4. Call `_build_paragraph_1`, `_build_paragraph_2`, `_build_paragraph_3`, `_build_order_text`.
5. Return fully-populated `RecommendationCard`.

The function never raises. Wrap in try/except; on exception, return a minimal card with `passed=False`, `gonogo_summary="INTERNAL_ERROR: {exc}"`, and empty narratives.
